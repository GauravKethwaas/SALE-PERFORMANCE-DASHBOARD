# SALE-PERFORMANCE-DASHBOARD

📌 Project Overview
This project is an interactive Sales Performance Dashboard developed in Power BI to analyze sales data and generate actionable business insights. The dashboard helps track revenue, product performance, seller contribution, sales trends, and payment methods through dynamic visualizations and filters.

🎯 Objective
The primary goal of this project is to transform raw sales data into meaningful insights that support data-driven decision-making and improve sales performance monitoring.
